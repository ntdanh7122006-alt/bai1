BÀI 1: LÀM QUEN VỚI NODE.JS
1. Mục tiêu
Làm quen với môi trường Node.js.
Biết cách viết và chạy chương trình JavaScript bằng Node.js.
Sử dụng lệnh console.log() để xuất dữ liệu ra màn hình Terminal.
2. Công cụ sử dụng
Visual Studio Code (VS Code).
Node.js.
npm (Node Package Manager).
3. Nội dung thực hành

Tạo file hello.js và viết chương trình sau:

javascript
console.log("Hello World!");
console.log("Chao mung den voi node.js.");
console.log("Node.js hoat dong thanh cong!");

4. Cách chạy chương trình

Mở Terminal trong VS Code và thực hiện lệnh:

bash
node hello.js

5. Kết quả

Khi chạy chương trình, Terminal hiển thị:

text
Hello World!
Chao mung den voi node.js.
Node.js hoat dong thanh cong!

6. Kết luận

Qua bài thực hành, em đã biết cách kiểm tra phiên bản Node.js, npm, tạo file JavaScript và chạy chương trình bằng Node.js thông qua Terminal trong Visual Studio Code.
